# Паола App — панель просмотра и быстрых отметок

Веб-приложение для рутины: сводка по календарю и задачам, привычки со
стриками и целями. Приложение не думает и не обращается к
Anthropic API — вся логика вывода данных детерминированная, выборки из
Notion и Google Calendar. Мышление и ресерч — в Claude.ai (через Notion MCP
на той же базе); бот Паола (`../bot.py`) выведен из эксплуатации.

Память — те же базы Notion, что у Second Brain: приложение видит те же
задачи, что и раньше видел бот.

## Архитектура

```
static/ (веб-интерфейс: Дом · Неделя)  ⇄  FastAPI (main.py)
                              ├─ services/ — Notion (async) · Google Calendar
                              ├─ digests.py — утренняя/вечерняя сводки (текст)
                              └─ scheduler.py — точка расширения планировщика
                                                (сейчас без фоновых job'ов)
```

## Подготовка Notion (один раз)

Создать базы и расшарить их той же интеграции, что у бота:

**Привычки** (`NOTION_HABITS_DB_ID`)
| Свойство | Тип | Значения |
|---|---|---|
| Привычка | Title | |
| Активна | Checkbox | |
| Тип | Select | `Да/Нет`, `Число` |
| Цель число | Number | для типа «Число» |
| Единица | Text | «шагов», «мин» |
| Цель | Text (необязательно) | текстовое описание — не участвует в расчёте |
| Порядок | Number | сортировка на Доме, по возрастанию; без значения — в конец |
| Группа | Text (необязательно) | заголовок секции на Доме («Витамины», «Самообразование»); пустая — привычка без заголовка, просто по порядку |

**Журнал привычек** (`NOTION_HABIT_LOG_DB_ID`)
| Свойство | Тип |
|---|---|
| Запись | Title |
| Привычка | Text |
| Дата | Date |
| Выполнено | Checkbox |
| Значение | Number |
| Заметка | Text |

Для типа «Число» день засчитан в стрик, если `Значение >= Цель число`; для
«Да/Нет» — по чекбоксу `Выполнено`, как раньше.

**Привычки на 21.09.2026 и их порядок на Доме** (поле «Порядок», группы —
поле «Группа»):
1. Вес (утро) — Число, кг, без цели (просто фиксация)
2. группа «Витамины»: Витамины утро — B total · Витамин D (день) ·
   Магний + глицин (вечер) — три отдельных Да/Нет
3. Вода — Число, л, цель 3 л/день
4. Шаги — Число, 8000/день
5. Сон до 23:00 — Да/Нет
6. группа «Самообразование»: Медитация · Чтение / аудиокниги (30 мин)
7. Спорт — Да/Нет

Порядок и группы правятся прямо в Notion (поля «Порядок»/«Группа»), без
изменений кода — рендер на Доме (`static/app.js`, `loadHabits`) просто
вставляет заголовок секции при смене группы в отсортированном списке.

**Вода — ввод стаканами.** На фронте привычка «Вода» (по имени) показывает
отдельный виджет: вводишь количество стаканов по 200 мл, в Notion уходит
пересчитанное значение в литрах (`services/notion.py`/база работают только
в литрах — конвертация только в `static/app.js`, константа `WATER_GLASS_L`).

**Бэкдейтинг — до 2 дней назад.** Над списком привычек — переключатель
Сегодня / Вчера / Позавчера (`static/app.js`, `HABITS_OFFSET`). Любая
отметка (чекбокс, число, вода) уходит в Notion с датой выбранного дня, не
обязательно сегодняшней — если не успела внести шаги/привычки в день,
можно внести на следующий день, но не позже, чем на второй. Окно задаётся
константой `HABITS_BACKDATE_DAYS` в `main.py`; `GET /api/habits` и
`POST /api/habits/log` валидируют дату через `_clamp_habit_date` (сегодня
и максимум 2 дня назад, иначе 400).

База «Задачи» — существующая, ID тот же, что у бота.

Напоминания как функция убраны 6 сентября 2026 (были пуш-канал через
Telegram, без него не имели смысла как отдельный блок).

## Задачи (создание из формы)

Кнопка «＋ задача» на Доме открывает форму с полями: задача (текст + голос),
зона, приоритет, дедлайн, комментарий. Значения зон и приоритетов — строго
фиксированный список (совпадает со значениями в Notion, эмодзи — часть
значения):
- Зоны: 💼 Бизнес, 👥 Networking, 💰 Финансы, 🏥 Salute, 🧠 Mental,
  🏠 Family, 💅 Beauty, ✈️ Viaggi, 🪞 Personal
- Приоритеты: ❗ Важное, ✅ Обычное, 🔜 Когда-нибудь

Правила выбора зоны/приоритета в код не переносятся — выбор делает Юлия
из списка при создании задачи.

## Консунтиво Generali (учёт часов и биллинг)

Учёт часов по клиенту Generali для фактуры. Три базы Notion под страницей
клиента «Generali»: **Consuntivo Generali** (строки-активности),
**Tariffe Generali** (тип → ставка €/час), **Reparti Generali** (справочник
департаментов). ID заданы дефолтами в `config.py`. Функции чтения/записи —
в `services/notion.py` (`get_reparti`, `get_tariffe`, `query_consuntivo`,
`create_consuntivo_rows`, `confirm_consuntivo_period`); отдельного UI/агента
для сбора консунтиво сейчас нет — история и базы сохранены для будущего
использования.

## Локальный запуск

```bash
cd paola-app
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить значения
uvicorn main:app --reload
# открыть http://127.0.0.1:8000
```

## Деплой на Railway (отдельный сервис)

1. Railway → New Service → тот же GitHub-репозиторий.
2. Settings → **Root Directory: `paola-app`** — сервис видит только эту папку.
3. Variables → скопировать по списку из `.env.example`.
4. Start command подтянется из `paola-app/Procfile`.
5. Networking → Generate Domain — это адрес приложения.

Рабочие ветки — `claude/название-задачи` → мерж в `master`.
